# 参考图分析：从图片提取可复用的参数

用户给出参考照片、剧照或喜欢的角色图时，**不要描述照片内容**——那是浪费。要做的是
把图片抽象成**可写进提示词的参数**。

一句话区分：

| 错误做法 | 正确做法 |
| --- | --- |
| "图里是一个鼻子很挺、眼神很冷的男生" | 提取"鼻梁起点在眉间下方约 1/4 眼高、鼻翼宽≈眼宽"这类比例 |
| "整体偏冷色调" | 提取"高光偏青、阴影偏中性灰、对比中等、颗粒细腻"这类影调参数 |

原因：形容词是可自由解释的，比例不是。提示词里写"鼻子很挺"，模型每次给你不同的鼻子；
写"鼻梁窄直、鼻头小而圆、鼻翼宽约等于单眼宽度"，才收敛到同一个鼻子。

---

## 一、面部几何：优先提取这七项

按**对辨识度的贡献**从高到低：

| 参数 | 怎么量 | 为什么重要 |
| --- | --- | --- |
| `face_ratio` | 脸长 / 脸宽（颧骨处最宽） | 决定"长脸 / 圆脸"的量级，比"修长椭圆"精确 |
| `eye_geometry` | 眼距 / 单眼宽；眼睛纵高 / 横宽 | 眼距是**最容易做出辨识度**的变量 |
| `eye_depth` | 眼球相对眉骨的深浅；是否有内双/眼皮覆盖 | 决定眼窝立体感的来源 |
| `jaw_geometry` | 下颌角开合度（宽下颌 ↔ 收下颌）；下巴前突量 | "锋利"与"圆厚"的本质差异 |
| `brow_geometry` | 眉密度、眉峰位置、眉与眼的间距 | 眉压眼 vs 眉高眼开，气质完全不同 |
| `nose_geometry` | 鼻梁起点高度、鼻梁宽度、鼻翼宽 / 脸宽 | 鼻子的辨识度主要在鼻翼与起点，不在"挺" |
| `lip_geometry` | 唇厚 / 唇宽比；唇峰角度；嘴角朝向 | 唇形的差异几乎全在这三项 |

**提取方式**：横向把脸分成五等分（经典五眼），纵向分成三等分（发际-眉-鼻底-下巴），
然后描述参考图相对这个标准网格**偏在哪里**。"偏在哪里"就是特征。

例：

```yaml
face_ratio: 1.45            # 略长于标准
eye_geometry: spacing=1.1   # 眼距略宽于单眼宽
eye_depth: hooded           # 上眼皮覆盖
jaw_geometry: angle=110     # 下颌角偏开 → 宽下颌
nose_geometry: root=low, alar=0.9
lip_geometry: fullness=0.6, bow=faint
```

## 二、风格提取：从剧照里读影调

**"同一部剧"的观感主要来自影调，不来自脸。** 参考图里如果有剧照，优先提取这些：

| 维度 | 提取什么 | 写进 `styleLock` 的形式 |
| --- | --- | --- |
| 高光色偏 | 高光是偏青、偏暖、还是中性白 | 高光偏青 |
| 阴影色偏 | 阴影是中性灰、还是带绿/带紫 | 阴影中性偏冷 |
| 对比强度 | 低/中/高，看最亮与最暗的分布 | 对比中等，暗部不死 |
| 饱和 | 整体低饱和还是有局部强色 | 整体低饱和，肤色是唯一暖点 |
| 颗粒与质感 | 数字干净 / 细腻胶片颗粒 / 明显颗粒 | 细腻颗粒，不锐化 |
| 光源性质 | 硬光还是柔光，主光高度，是否有轮廓光 | 柔光箱略高于视线，弱轮廓光 |
| 镜头感 | 焦外程度、透视压缩感 | 85mm，f/2.8，轻焦外 |

## 三、把提取结果落成池子扩展

**新增枚举值必须先登记进 `element-pools.md`，再在角色卡里使用。**
不登记就直接用 = 临时造词 = 同批语义漂移。

追加到 `element-pools.md` 的格式：

```
### 扩展池：<来源标签，如 ref-2026-10-batch1>
| 字段 | 新增可选值 |
| --- | --- |
| face_ratio | `1.35-standard` / `1.45-slightly-long` / `1.60-markedly-long` |
| eye_geometry | `spacing-wide-1.1` / `spacing-narrow-0.9` / `standard-1.0` |
```

**来源标签的作用**：以后成图效果不对时，能回溯是哪一批参考图引入的。

## 四、版权与伦理边界

参考图是用来提取**通用比例规律与影调特征**的，不是用来复刻的。

| 可以做 | 不可以做 |
| --- | --- |
| 提取骨相比例、五官几何、影调特征 | 在提示词里写某个具体名人的名字作为长相依据 |
| 提取"这一类型的脸"的共性 | 复刻某张照片的构图、姿态、服装细节 |
| 把特征抽象成参数 | 让参考图直接充当生成图（那不是本 Skill 的范围） |
| 提取主流商业摄影的通用影调 | 复刻某个品牌的视觉识别系统 |

**判定标准**：如果提示词里出现"像某某人"，就是越界了。应该出现的是参数与描述。

这条不只是伦理要求，也是**效果要求**——生图模型对具体人名的反应不可控，
而参数是可控的。

## 五、一批参考图的处理流程

```
① 逐张提取几何与影调参数（记录到临时表）
        ↓
② 找共性：多张图反复出现的特征 = 用户偏好
   例：十张里七张是"眼距略宽 + 下颌收 + 低饱和冷调"
        ↓
③ 落池：把共性登记成 element-pools 的扩展池
        ↓
④ 取风格：把影调共性写进 styleLock 模板
        ↓
⑤ 保留少数派：不要求十张全一致。
   剩下的三张差异恰恰是"下一批角色"的多样性来源
```

**第 ⑤ 步容易被忽略**：用户给一批图，往往是想复制其中**最主流的那一类**，
但整批角色全按主流风格做会立刻模板化。正确做法是：主流特征作为基调，
差异特征作为批次内角色之间的区分手段。

---

## 六、没有参考图时怎么办

降级顺序：

1. 从题材推断标准档（青春片 / 都市剧 / 罪案剧各有默认影调）
2. 用 `element-pools.md` 现有枚举，按 `casting_type` 取特征倾向
3. 按 `face-diversity.md` 的差异下限，保证角色之间够不同

**没有参考图不代表质量必然低**——但会缺一层"用户具体偏好"的收敛，
所以有参考图时一定要用，哪怕只有两三张。
