## 一、按人物分组

16 张图里有 8 张含明确可辨人物，按"能确认是同一个人的多角度"分组：

### 组 A · 深肤色女性（多角度，提取条件最好）

出现于：波点吊带特写、惊讶特写（雀斑）、走廊双人。

| 维度 | 观察 |
| --- | --- |
| 肤色 | **中等深度的暖调古铜**，不是极深，质地有自然光泽与油感 |
| 面部特征 | **雀斑明显**（颊部与鼻梁），这是她最强的辨识符号 |
| 脸型 | 椭圆偏圆，轮廓饱满 |
| 眼 | **深棕，大而圆**，眼白清亮，双眼皮明显 |
| 眉 | **浓密、深色、自然弧形**，眉峰略高 |
| 鼻 | 鼻梁中等，**鼻头圆润、鼻翼略宽** |
| 唇 | **饱满、唇纹明显**，唇峰柔和 |
| 发 | **深棕带焦糖挑染**，中长、大波浪、发量厚 |
| 气质 | 情绪外放，表情强烈（惊讶、激动） |
| 服装 | 红色波点挂脖吊带（唯一亮色） |

**提取要点**：雀斑 + 挑染波浪发 + 饱满唇，三者组合是她。**雀斑必须写进提示词并加负面保护**，否则会被模型抹掉。

### 组 B · 深肤色男性（多角度）

出现于：看台四人、四人惊讶、棒球场双人。

| 维度 | 观察 |
| --- | --- |
| 肤色 | **中等偏深暖调**，与组 A 相近但更偏棕 |
| 脸型 | 偏长、轮廓清晰，下颌线条干净 |
| 眼 | 深棕，中等大小 |
| 眉 | **浓密、深色** |
| 发 | **黑色短卷发**，紧贴头皮的卷度，发际线整齐、两侧收短 |
| 气质 | 表情丰富、有喜感，常是群体中的活跃者 |
| 服装 | 白色系校服/运动上衣，深色运动外套 |

### 组 C · 男性 · 深色厚发（多角度）

出现于：窗边看手机、棒球场双人（校队夹克）、夜间皱眉。

| 维度 | 观察 |
| --- | --- |
| 肤色 | **暖调浅色**（与组 A/B 明显不同） |
| 脸型 | **长而窄，下颌清晰**，"古典比例" |
| 眉 | **浓密、近黑、眉压低**（本组最强特征） |
| 眼 | **深棕、眼窝较深**，眼神沉静偏忧郁 |
| 鼻 | **鼻梁高挺笔直**，鼻头精致 |
| 唇 | 中等饱满、唇线清楚 |
| 发 | **深棕黑、中长、厚实有体积**，自然纹理，额前垂落碎发 |
| 气质 | 内敛、克制，情绪压在表情下面 |
| 服装 | 深灰连帽衫、深藏青校队夹克、黑色衬衫 |

**注意与组 B 的区别**：两人都是深色短/中发男性，但**肤色差一个档**（暖浅 vs 暖深），
脸型也相反（长窄 vs 偏长圆润）。这正是"族裔不等于骨相"的例子。

### 组 D · 女性 · 黑框眼镜（多角度）

出现于：图书馆/室内特写、居家、打电话、走廊。

| 维度 | 观察 |
| --- | --- |
| 肤色 | **暖调浅白**，带自然红润 |
| 脸型 | **长窄、轮廓流畅**，下颌柔和 |
| 眼 | **深棕，双眼皮明显**，眼型偏长 |
| 眉 | 中等浓密，自然弧形 |
| 鼻 | 鼻梁笔直、鼻头小巧 |
| 唇 | **中等偏饱满**，唇峰明显 |
| 发 | **深棕带红调、长直**，中分，发量中等 |
| 标志物 | **黑框眼镜**（贯穿所有出场，是第一辨识符号） |
| 服装 | 浅蓝背心、蓝运动背心、白色上衣 |

**提取要点**：眼镜必须写进提示词。去掉它，这个角色的辨识度损失过半。

### 组 E · 成年男性（权威型）

| 维度 | 观察 |

| 气质 | 权威、压抑的怒气 |

### 组 F · 成年女性

出现于：餐桌、办公室打电话。

| 维度 | 观察 |
| --- | --- |
| 年龄感 | **40 代** |

| 服装 | 白衬衫（家居）/ 深藏青西装 + 细条纹衬衫（办公） |
| 气质 | 克制的疲惫，或职业性的严肃 |

## 二、批次影调（写进 `styleLock`）

从这 16 张图提取：

```yaml
# 影调
highlight_tint: 中性偏暖（室内橙调明显）/ 日光场景偏暖金
shadow_tint: 暖褐，不发蓝
contrast: 中低，暗部保留细节
saturation: 低到中，肤色是暖点，环境偏灰
skin: 保留真实纹理，可见雀斑与毛孔，**不磨皮**

# 质感
grain: 细腻自然
sharpness: 柔和，不锐化
depth_of_field: 浅（背景明显虚化）

# 光线
lighting_nature: 柔光为主
lighting_source:
  interior: 侧窗自然光 + 室内暖光，常带橙色实用光源
  exterior: 日光偏暖
rim_light: 无明显轮廓光

# 构图
framing: 胸像到半身为主，多特写
camera_height: 平视
```

## 三、服装体系

| 场景 | 单品 |
| --- | --- |
| 校园日常 | 校队夹克（深藏青+白）、连帽衫（灰/黑）、格子衬衫 |
| 校服/运动 | 白色运动上衣、深色运动外套、篮球背心 |
| 家具居 | 白色衬衫、T恤、开衫 |
| 正式/职场 | 深藏青西装、细条纹衬衫、浅蓝 Polo |
| 聚会 | 红色波点吊带、丹宁夹克 |

**配色规律**：中性色打底（灰、白、米、牛仔蓝），**每套一个亮色**
（红色波点、黄色、粉色）。与 v1/v2 提取的规律一致。
