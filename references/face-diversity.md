# 面部多样性：防模板化的机制

## 为什么需要这个文件

人像生成最顽固的失败模式不是崩坏，而是**千人一面**。典型的模板脸是：
修长椭圆脸 + 清晰下颌 + 立体眉骨 + 高挺鼻梁 + 清晰唇形 + 冷白皮肤。
六个维度全部取"标准好看"档，换掉发色和衣服，出来还是同一个人。

**根因是把两条规则合并了**，而它们必须分开：

- `identity` 身份锚的约束是「**同一个角色**跨多张图不许变脸」
- 它**不是**「所有角色共用一张脸」

前者是稳定性要求，后者是多样性要求。二者不冲突，但必须分别写进流程。

---

## 铁律

**1. 角色之间，`identity` 完全可替换 —— 不是只换配色。**
换角色时改的是骨相、眼型、鼻型、唇型、皮肤质感本身，不只是把浅灰蓝改成深棕。

**2. 同一角色之内，`identity` 冻结 —— 一个字不许改。**

**3. 差异下限（硬规则）：同批任意两个角色，`identity` 九项中至少 4 项不同。**

九项是：`face_shape` / `jawline` / `chin` / `cheekbones` / `brow_ridge` /
`eyes.shape` / `nose.bridge` / `nose.tip` / `lips.fullness`

外加两项必查：`eyes.color`、`hair.color`。

只改 1–2 项 = 同一个人换了衣服。这是模板化的判定线。

---

## 关键机制：靠**结构**区分，不靠瑕疵

真实的人脸靠**结构差异**被记住：脸型骨架、五官比例、眼型、鼻型、唇型、发型、气质。
**不是**靠雀斑、痘印、痣、疤痕、眼袋这类皮肤缺陷——观众看到脏脸时，
读到的是"这张脸没做好"，而不是"这是另一个人"。

- **允许"不完美的结构"，不允许"脏的皮肤"。**
  结构上完全可以偏离标准（宽下颌、圆厚脸、招风耳、窄长脸），这是多样性的正当来源；
  皮肤上默认走 `clean-polished`（干净均匀、保留毛孔质感）。
- `distinctive_features` 与 `asymmetry` 都是**可选**字段，默认 `none`。
  只有剧情/职业需要人物痕迹时才用，并在卡里写明原因，同时把
  `skin.idealization` 设为 `character-blemished`。
- 唯一允许作为"好看的特征"进入 `distinctive_features` 的是魅力点：
  酒窝、年轻笑纹、门牙缝。**痣、雀斑、疤、压痕、眼袋不算魅力点**，属缺陷档。

参见要素池 §2「辨识度维度」与 §3 `skin.idealization`。

## 选角类型 → 面部特征模板

选角类型决定**面部特征的取用倾向**。这是防模板化最有效的单一机制：
不同类型的人从不同模板取特征，而不是从同一个"好看"模板里挑参数。

| 选角类型 | 脸型倾向 | 五官倾向 | 特征倾向 | 皮肤倾向 |
| --- | --- | --- | --- | --- |
| `leading-man` 主角型 | 修长椭圆 / 长方 / 方棱 | 对称、立体眉骨、直高鼻梁 | 干净，少特征 | 均匀通透 |
| `leading-woman` 主角型（女） | 修长椭圆 / 心形 / 柔椭圆 | 精致、对称 | 干净，少特征 | 均匀通透 |
| `jock-athlete` 运动型 | 方棱 / 长方 / 圆厚 | 宽下颌、鼻梁宽或曾断过、眉浓 | 鼻梁微歪、下巴擦伤疤 | 易晒红、有雀斑 |
| `girl-next-door` 邻家型（女） | 圆软 / 椭圆偏圆 | 圆眼、鼻头圆、唇饱满 | 酒窝、浅雀斑 | 暖调、有雀斑 |
| `brain-nerd` 学霸型 | 长方 / 三角 / 窄长 | 深眼窝、发际线偏高、鼻梁窄 | 眼镜压痕、额前痘印 | 偏白、少血色 |
| `goth-alt` 另类型 | 心形 / 菱形 / 窄长 | 重眼线、鼻梁窄直、唇薄 | 唇钉、耳洞、苍白 | 苍白、低血色 |
| `cheer-captain` 啦啦队长型（女） | 心形 / 圆润 | 大圆眼、笑眼、鼻头微翘 | 酒窝、马尾压痕 | 健康小麦或暖白 |
| `bad-boy` 叛逆型 | 方棱 / 长窄 | 眼窝深、眉峰高、下颌角明显 | 眉间疤、唇周胡茬痕 | 偏暗、有瑕疵 |
| `rich-preppy` 富家型 | 椭圆 / 长方 | 标准对称、鼻梁直 | 干净、牙整 | 均匀、偏白 |
| `outsider-weird` 怪咖型 | 圆 / 三角 / 窄长 | 眼距宽、鼻头圆大、唇薄 | 龅牙、招风耳、痣 | 不均、局部泛红 |
| `character-actor` 性格演员型 | 任意不规则 | 任意不对称 | **必须 ≥2 项特征** | 任意 |
| `hard-worker` 蓝领型 | 方厚 / 圆厚 | 鼻梁宽、眉压眼、唇厚 | 下颌擦伤、手部粗糙 | 晒伤、风霜感 |

**使用方式**：先定 `casting_type`，再从对应行的**结构列**（脸型 / 五官倾向）挑具体枚举值。

**⚠️ 表中"特征倾向"一列按 `skin.idealization` 分档取用**：
`clean-polished`（默认，主角/校草/偶像）**只取结构倾向，忽略该列中的疤痕、痘印、压痕、
胡茬、晒伤等缺陷项**；这些缺陷项仅属于 `character-blemished` 档（蓝领、病人、战损、剧情需要）。
`character-actor` 的"至少两项特征"要求同理，只在 `character-blemished` 档生效，
`clean-polished` 档用**结构不规则**（任意脸型、不对称骨相）替代，不必往脸上加瑕疵。

## 自检：这张脸是不是模板脸？

编译提示词前，对着角色卡问五个问题：

1. 九项骨相/五官里，有**几项是"精致/清晰/流畅/高挺"这一档**？超过 5 项就是模板脸。
2. 把这张卡和同批其他角色的卡并排，能一眼说出差别在哪**三个具体的结构字段**吗
   （脸型 / 下颌 / 颧骨 / 眉骨 / 眼型 / 鼻型 / 唇型）？
3. 如果只把发色和衣服换掉，这张脸会不会变成同一个人？会的话，回去改骨相。
4. 有没有把**雀斑、痘印、痣、疤、眼袋、压痕**写进正面描述？有的话删掉，
   除非 `skin.idealization: character-blemished` 且人设确实需要。
5. `skin.idealization` 声明了吗？主角/校草/偶像档必须是 `clean-polished`。

## 反模式

| 反模式 | 后果 | 修正 |
| --- | --- | --- |
| 九个骨相维度全取"标致"档 | 整批同一张脸 | 至少 3 项取非标准档 |
| **用雀斑 / 痘印 / 痣 / 疤 / 眼袋给角色"做区分"** | 观众看到的是脏脸，且主角档直接被毁 | 区分只能靠骨相与五官比例、发型、气质、配色；皮肤走 `clean-polished` |
| 换角色只改 `eyes.color` + `hair.color` | 双胞胎 | 按差异下限，骨相至少 4 项不同 |
| 女性角色一律"精致下颌 + 小脸" | 女性全套同一张脸 | 启用圆软、方棱、窄长等非标准档 |
| 把所有角色都设成 `leading-man` | 全批都是主角脸，没有配角 | 混用 `jock-athlete` / `brain-nerd` / `character-actor` |
| 为了"真实感"往主角脸上加缺陷 | 校草/偶像档直接不成立 | 真实感来自毛孔质感与光位，不来自缺陷；缺陷只属于 `character-blemished` 档 |
