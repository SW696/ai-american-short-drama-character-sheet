# 一致性与自查清单

本文件只管**提示词内部**的一致性，不涉及任何生成链路。

---

## 一、一致性的三个层次（不要混淆）

| 层次 | 约束什么 | 由谁保证 |
| --- | --- | --- |
| **图内一致** | 同一张图里多个视图是同一人 | 提示词里的显式锚点句 |
| **同角色跨图一致** | 同一角色的多种造型不变脸 | L3–L4 段落逐字复制 |
| **跨角色差异** | 不同角色不能长成同一个人 | 差异下限 + 选角类型 |

**最常见的错误是把前两层当成一层。**
"图内一致"要求"完全一致"；"跨角色"要求"必须不同"。这两句话同时出现在一个批次里
并不矛盾，但必须分别写给不同的对象。

---

## 二、图内一致性（多视图版式专属）

四格或双视图版式在一张图里画同一个人多次，靠**显式声明**承接，不靠重复名词。

**必须包含的锚点句**：

```
左右人物的面部特征、发型、肤色、服装完全一致
```

或英文：

```
all features identical across both views
```

**为什么不能省**：仅在两处分别描述同一个人，模型并不认为它们是同一人。
它会按自己的理解各画一张脸。

**四格版式的额外机制**：正面与侧面全身图故意糊脸，因此**图内一致性压力被消掉**——
只有左侧头像需要清晰。此时发型发色成为唯一身份线索，必须显式描述背面视图的后发长度与发尾。

---

## 三、同角色跨图一致性（多造型专属）

**唯一手段：L3–L4 段逐字复制。** 这是纯文本模式下的一致性上限。

| 正确 | 错误 |
| --- | --- |
| 把 L3–L4 当作一整块不可编辑的文本，每次原样粘贴 | 每次照着角色卡重新"写一遍"这段 |

**为什么这是硬规则**：手抄或重写时，人会不自觉改写措辞。
"下颌线锋利干净" → "下颌线条清晰锐利"，**含义完全相同，但模型把它当两句不同的话处理**。
这是最隐蔽也最常见的漂移来源。

**操作方式**：编好第一种造型的提示词后，把 L3 与 L4 两段单独存下来，
第二种造型只重写 L5（服装）和 L2（版式/姿态），其余原样拼接。

**同时提醒用户**：即使逐字复制，纯文本生成也不能保证跨图完全一致。
想要精确一致，需要支持垫图（参考图）的工具，或在一次生成里出完所有造型。
**本 Skill 不承诺跨图锁脸**——这是提示词方式的固有限制，应如实说明而不是暗示可以做到。

---

## 四、跨角色差异（批量专属）

按 [face-diversity.md](face-diversity.md) 的差异下限执行：

- `identity` 九项中至少 **4 项不同**
- `eyes.color`、`hair.color` 必查
- **区分只能靠结构**（骨相 / 五官比例 / 发型 / 气质 / 配色）——
  禁止用雀斑、痘印、痣、疤、眼袋、压痕等皮肤缺陷做区分手段
- 每张卡都要声明 `skin.idealization`；主角/校草/偶像档为 `clean-polished`
- 提示词必须携带**防磨皮**反向约束（`plastic_skin` / `over_smoothed` / `airbrushed`）；
  "不得理想化 / 不得去除瑕疵"两句**只在 `natural-real` 与 `character-blemished` 档**携带

只改发色和配色 = 同一个人换了衣服。

## 五、交付前自查清单

### A. 提示词完整性
- [ ] 是一段**可直接全选复制**的完整文本，不依赖任何外部说明
- [ ] 没有夹带字段名、内部术语、本 Skill 的流程说明
- [ ] 中英版本内容一致（若双出）

### B. 版式契约
- [ ] 明确说了有几个视图、各是什么
- [ ] 四格版式：写明左侧头像清晰、右侧正面与侧面糊脸、背面保留头部
- [ ] 双视图版式：写明左特写、右全身、头顶至鞋底完整
- [ ] 画面内无任何文字（独立写进负面层）

### C. 图内一致性
- [ ] 包含"面部特征、发型、肤色、服装完全一致"这一句
- [ ] 身份锚只写一次，两个视图共用

### D. 角色卡符合度
- [ ] 眼睛颜色与眼型符合卡面
- [ ] 眉色/眉形符合，未被美颜淡化
- [ ] 鼻梁与鼻头符合，未被风格化
- [ ] 唇形与唇峰符合
- [ ] 年龄感符合 `age_range`
- [ ] `facial_hair` 与负面层一致（无胡须角色必须带负面项）

### E. 真实感（对抗塑料脸）
- [ ] 有明确的皮肤质感要求（毛孔、细纹、纹理）
- [ ] 没有 `8K` / `ultra detailed` / `flawless` / `masterpiece` 这类堆词
- [ ] 负面层含 `plastic_skin` / `over_smoothed`

### F. 跨角色差异（批量专属，单角色跳过）
- [ ] 任意两角色九项中至少 4 项不同
- [ ] 差异全部来自结构（骨相/五官/发型/气质/配色），没有任何角色靠皮肤缺陷区分
- [ ] 每张卡都声明了 `skin.idealization`，主角/校草档为 `clean-polished`
- [ ] 正面描述里没有雀斑/痘印/痣/疤/眼袋/压痕（`character-blemished` 档除外）
- [ ] 都带了防磨皮反向约束句
- [ ] 风格锁全批一致，未被逐角色改写

## 六、失败模式 → 改哪一层

**这张表的价值在于定位**：不靠运气重抽，而是知道该改提示词的哪一段。

| 现象 | 根因在哪一层 | 改什么 |
| --- | --- | --- |
| 多视图不是同一人 | L2 版式层 | 补一致性锚点句；身份锚只写一次 |
| 脚被裁掉 | L6 摄影层 | 补"完整显示头顶至鞋底"，负面加 `cropped_feet` |
| 头盔/道具被裁 | L6 摄影层 | 负面补 `cropped_<道具名>` |
| 手部畸形 | L6 摄影层 | 写"双手自然垂落"或明确持握方式，负面加手部集 |
| 皮肤塑料感 | L6 皮肤描述 | 删堆词，改具体纹理要求，负面加 `plastic_skin` |
| 画面出现文字 | L7 负面层 | 独立覆盖 `text` / `letters` |
| 设定板长出标签、比例尺、网格 | L7 负面层 | 补 `scale bars` / `labels` / `grid lines` |
| 特写被画成普通正面照 | L6 摄影层 | 列左视图的证据项（瞳孔、眉眼、鼻梁、唇形、皮肤） |
| 换造型后不像同一人 | 编译环节 | 检查 L3–L4 是否逐字复制 |
| 整批脸相似 | 角色卡环节 | 检查差异下限与选角类型是否错开 |
| 五官被美颜抹平 | L7 负面层 | 补防磨皮项（`plastic_skin` / `over_smoothed`），**不要**用"不得理想化"（那会把脸弄脏） |
| 主角脸上出现雀斑/痘印/痣/疤 | 抽卡 + L7 负面层 | 卡里 `skin.idealization: clean-polished`、`freckles_or_marks: none`、`skin_extra: none`；正面写明"肤色干净均匀"；删掉"不得理想化/不得去除瑕疵" |
| 女性角色出现男性骨相 | 抽卡环节 | 按要素池 §0 检查 gender 三处是否同步切换 |

---

## 七、交付时对用户说清楚的三件事

1. **提示词直接复制即可**，不需要改任何东西；要改就改角色卡再重新编译，比手改提示词安全。
2. **同角色多造型时**，L3–L4 必须原样保留——如果用户自己删改这段，脸会变。
3. **纯文本生成不保证跨图锁脸**。想要同一角色多张图完全一致，用支持参考图的工具，
   或把所有造型放进一次生成。
